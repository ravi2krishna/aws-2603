    -> Data center

        -> A data center is a physical facility or building that houses 
        groups of networked computer servers, data storage drives, and network equipment 
        used by companies to store, process, and share digital information and run applications.

        -> https://datacenters.microsoft.com/wp-content/uploads/2025/11/OMB-Datacenter-11_11-Hero.jpg

        -> Main Parts of a Data Center:
        
            -> Servers: 
                
                -> High-power computers that process data and run software programs.
                
            -> Storage Systems: 
            
                -> Hard drives and arrays that hold large amounts of digital files and records.
                
            -> Network Gear: 
            
                -> Routers, switches, and firewalls that move data safely in and out of the facility.
                
            -> Cooling and Power: 
            
                -> Heavy-duty air conditioners, fans, backup generators, and power grids to 
                keep machines running non-stop.

        -> Setting Up Data center physically 

            -> First, We Need To Buy / Lease Land 

            -> Construct / Rent a physical building 

            -> Need To Hire Security Personnel To Mange Building 

            -> We Need To Buy Computer Components Like Servers, 
            Storage Systems, Network Gear, Cooling, Power etc

            -> Once Components Received, we need to hire Human Resources 
            to manage Servers, Storage Systems, Network Gear, Cooling, Power 
            Server Admins, Storage Admins, Network Admins, AC Technicians, Electricians etc 

        -> NOTE: To Setup and Manage datacenters, we need lot of expenditure(expenses) and 
        lot of human resources to manage, which needs a loy of time and money.

Class - 2
==========

    -> Cloud Offerings 

        -> Cloud Offerings Provide On-Demand Access to 
        Computing, Storage, Network and Softwares Resources Over the Internet. 

            -> IAAS - Infrastructure As A Service 

            -> PAAS - Platform As A Service 

            -> SAAS - Software As A Service 

        -> NOTE: Similar To Online Ride Offerings (Rapido)
        Scooty, Bike, Autos, Hatchback Cars, Sedan Cars, SUV Cars 

            -> As a customer i want Bus or Truck, Not Available 


        -> IAAS - Infrastructure As A Service 

            -> IAAS Model Provides Raw Computing Infrastructure Like Servers, Storage, Network

            -> You Manage Underlying Components On Top Of Infrastructure 

            -> https://miro.medium.com/v2/resize:fit:1400/1*VIzchB0D3t1awTzj3sfe1g.png

            -> Server For Myntra Application

                -> Hardware and Virtualization will be provided and managed by Vendor 

                    -> 4 CPU's - 16 GB RAM - 500 GB SSD Storage - Networking 

                -> As Customer (You) Need To Manage 

                    -> Linux Ubuntu Operating System

                    -> Tomcat / Jboss / Web Logic  

                    -> Runtime (Java, Python etc)

                    -> Data (Code, Database)

                    -> Myntra Application Running 

                -> Examples: AWS EC2 - AWS VPC - etc 

                -> Cost: ₹₹₹₹ 

                -> Human Resources: More (Different Admin, Developers)


        
        -> PAAS - Platform As A Service 

            -> PAAS Model Delivers Frameworks For "Developers" 
            to Build, Test and Deploy Softwares / Applications 
            Without Managing Underlying Hardware, Middleware and Runtime.

            -> Server For Myntra Application With Linux Ubuntu Operating System, 
            Tomcat Server and Java Runtime.

            -> Hardware, Virtualization and Platform For You Applications 
            will also be provided and managed by Vendor 

                -> 4 CPU's - 16 GB RAM - 500 GB SSD Storage - Networking - Linux Ubuntu OS -> Tomcat Installed and Running -> Java Installed 
                    
            -> As Customer (You) Need To Manage 

                -> Data and Applications Only 

            -> Examples: AWS Elastic Beanstalk - AWS RDS - AWS EKS etc 

            -> Human Resources: Less (Developers)
            
            -> Cost: ₹₹₹₹₹₹₹₹₹

        
            -> NOTE: We may use standalone Service i.e Only IAAS or Combine IAAS + PAAS 

            -> Myntra Application Requires (Developers Perspective)

                -> Web Server it's easy to manage - IAAS 

                -> Database Server it's bit difficult to manage - so i will choose PAAS 

                -> Solution 1 : Web Server (IAAS) + Database Server (IAAS) - ₹₹

                -> Solution 2 : Web Server (IAAS) + Database Server (PAAS) - ₹₹₹₹ 

                -> Solution 3 : Web Server (PAAS) + Database Server (PAAS) - ₹₹₹₹₹₹₹₹₹₹ 

        
        
        -> SAAS - Software As A Service 

            -> SAAS Model Provides Fully Functional and Ready To Use Softwares / Applications 

            -> Generally Accessed Via Web Browsers 

            -> Examples: Salesforce - Microsoft 365 - Google Workspace 

            -> Server For Myntra Application With Linux Ubuntu Operating System, 
            Tomcat Server, Java Runtime, Design Database and Code Myntra Application. 

            -> Hardware, Virtualization, Platform and Application also provided and managed by Vendor 

                -> 4 CPU's - 16 GB RAM - 500 GB SSD Storage - Networking - Linux Ubuntu OS -> Tomcat Installed and Running -> Java Installed -> Data and Applications is also ready to use 
                    
            -> As Customer (You) Need To Manage 

                -> NOTHING 

            -> Examples From AWS: AWS Chime(Online Meetings, Video Conferences) - AWS Workspaces etc 


            -> Customer-1: Needs Only Hardware i.e Only IaaS

            -> Customer-2: Needs Hardware + Platform i.e IaaS + PaaS 

            -> Customer-3: Needs Direct Application i.e SaaS 


        -> IaaS: Rent Infrastructure - You Manage OS, Middleware & Apps - AWS EC2, AWS VPC, AWS EBS

        -> PaaS: Build & Deploy Apps - You Manage Apps - AWS Elastic Beanstalk - AWS RDS, AWS EKS 

        -> SaaS: Use Apps - vendor manages everything - AWS Chime - AWS Connect - AWS Workspaces

    -> Cloud Terminology

        -> High Availability

            accessible and operational (24 X 7)

            -> https://drive.google.com/file/d/16O-aDK-g_CCJpWoyvho79f_H2SUplCT2/view - No High Availability

        -> Fault Tolerance 

            -> Fault Tolerance in AWS refers to the ability of a system to continue 
            operating without interruption in the event of hardware failures 

            -> Fault Tolerance is associated with Self Healing 

            -> https://assets.enterprisestorageforum.com/uploads/2021/02/understanding-fault-tolerance-securing-your-system_6019c7b9d29a4.png 

            -> NOTE: Just like a power generator, will be active when we lose power in building 

                -> A building without power generator is not Fault Tolerant 

                -> A building with power generator is Fault Tolerant 

            -> https://media.licdn.com/dms/image/v2/D5612AQEAzCREjM2taA/article-cover_image-shrink_720_1280/article-cover_image-shrink_720_1280/0/1725775705951?e=2147483647&v=beta&t=KvlTnTdCqnEQHIve0aGoksUSxAG69UalK3GLGcDgUso

                -> NOTE: A Fault Tolerant System is indirectly an Highly Available System 


        -> Scalability 

            -> Scalability in AWS refers to the ability of a system to handle 
            increasing workloads and accommodate according to growing demands.

            -> https://steadybit.com/wp-content/uploads/2025/09/validate-aws-ecs-auto-scaling-comp.png

                -> Increasing Hardware Resources - Scale Up 

                -> Decreasing Hardware Resources - Scale Down 

                -> Horizontal Scaling vs Vertical Scaling

        
        -> Security 

            -> Security in AWS refers to the measures taken to protect cloud resources
            and applications from Unauthorized Access. 

                -> Account Level Security 

                -> Application Level Security
