    -> Data center

        -> A data center is a physical facility or building that houses 
        groups of networked computer servers, data storage drives, and network equipment 
        used by companies to store, process, and share digital information and run applications.

        -> https://datacenters.microsoft.com/wp-content/uploads/2025/11/OMB-Datacenter-11_11-Hero.jpg

        -> Main Parts of a Data Center:
        
            -> Servers: 
                
                -> High-power computers that process data and run software programs.
                
            -> Storage Systems: 
            
                -> Hard drives and arrays that hold large amounts of digital files and records.
                
            -> Network Gear: 
            
                -> Routers, switches, and firewalls that move data safely in and out of the facility.
                
            -> Cooling and Power: 
            
                -> Heavy-duty air conditioners, fans, backup generators, and power grids to 
                keep machines running non-stop.

        -> Setting Up Data center physically 

            -> First, We Need To Buy / Lease Land 

            -> Construct / Rent a physical building 

            -> Need To Hire Security Personnel To Mange Building 

            -> We Need To Buy Computer Components Like Servers, 
            Storage Systems, Network Gear, Cooling, Power etc

            -> Once Components Received, we need to hire Human Resources 
            to manage Servers, Storage Systems, Network Gear, Cooling, Power 
            Server Admins, Storage Admins, Network Admins, AC Technicians, Electricians etc 

        -> NOTE: To Setup and Manage datacenters, we need lot of expenditure(expenses) and 
        lot of human resources to manage, which needs a loy of time and money.
