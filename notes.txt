        -> In Terms Of AWS, Infrastructure Is Made Of 

            -> Regions

        -> Regions 

            -> In AWS Region is a Geographic Location 

            -> Each region contains multiple isolated Availability Zones

            -> Regions operate completely independently from 
            one another to prevent cascading failures.

            -> Choosing a region close to your users minimizes network delay.

                -> https://cdn.britannica.com/96/212396-050-1FC95D3E/world-map-with-country-borders.jpg

            -> Compliance: Keep data inside specific geographic borders to meet legal rules.

            -> Cost: Prices for services can change depending on the region.

            -> New features or specific instance types may launch in certain regions first.


        -> Availability Zones (AZ)

            -> An AWS Availability Zone (AZ) is one or more discrete data centers with 
            redundant power, cooling, and networking within an AWS Region.

            -> Every region has at least three physically separate and isolated 
            data center groups to ensure high availability.

            -> Each AZ is physically separated by a meaningful distance (up to 100 km) 
            to prevent localized disasters from affecting multiple zones, 
            yet they are interconnected via high-bandwidth, low-latency private 
            fiber-optic networks.

            -> https://www.researchgate.net/profile/Ivan_Beres/publication/360541079/figure/fig1/AS:1154856056291328@1652350548135/AWS-Regions-and-Availability-Zones-Scott-nd.ppm

    -> VPC Components 

        -> Subnets
        
            -> Segments of a VPC's IP address range that group resources based on 
            security and connectivity needs (e.g., public subnets for websites, 
            private subnets for databases).

            -> A subnet or sub network is an logical subdivision of an Amazon Virtual Private Cloud (VPC)

            -> Most Popular Applications
        
                -> https://en.wikipedia.org/wiki/Programming_languages_used_in_most_popular_websites


        -> Route Tables 

            -> Rules that dictate where network traffic is directed.

            -> A route table contains a set of rules called routes, 
            that are used to determine where network traffic is directed.

        
        -> Gateways 

            -> Connection points that bridge your VPC to the external internet

            -> Internet Gateway

                -> An Internet Gateway must be attached to a VPC if the resources inside the VPC 
                need to connect to resources via the open internet.


        -> Network Access Control List (NACL)

            -> Virtual firewalls that control inbound and outbound traffic at the subnet level.


        -> Security Groups (SG)

            -> Virtual firewalls that control inbound and outbound traffic at the instance level.

        -> Subnetting is the practice of dividing a network into 
        two or more smaller networks 

        -> When You Create VPC and Subnet, You Must Specify CIDR Block 

        -> NOTE: AWS Allowed CIDR Block Size is in between /16 to /28 

            -> /16 - Maximum - 65536 Devices / IP Address 

            -> /28 - Minimum - 16 Devices / IP Address 

            /16 - 65536 Devices / IP Address 

            /28 - 16 Devices / IP Address 

            Allowed is 16 to 28 

            Total Bits in NW is 32 Bits
            Result = Total Bits - Your Netmask(NM)
            No Of Devices / IP Address = 2 ^ Result

            NM
